实验数据目录的组织方式

把原始数据、配置与分析结果放在明确的位置。

2026.10.09王青洲示例笔记
本文为网站的示例笔记，用于预览阅读版式；可替换成你的实际研究与学习记录。

每次实验使用独立目录，同时保存原始数据、配置文件与简短说明。处理结果另行存放，并记录生成它的脚本版本。命名规则保持简单一致，优先帮助未来的自己找到数据、理解条件和重复分析。

一份目录示例

experiment-001/
  README.txt         # 本次实验的问题与条件
  config/            # 参数与环境说明
  raw/               # 原始数据
  scripts/           # 本次使用的分析代码
  processed/         # 处理后的数据
  figures/           # 图表与生成说明
  observations.txt   # 观察、异常与待验证问题

README 里先写清这些

  • 实验想回答什么问题。
  • 数据文件来自哪里，字段如何解释。
  • 使用了哪些配置，代码对应哪个版本。
  • 哪些结果已经检查，哪些问题尚未确认。

这是一个可调整的组织示例。文件较少时可以更简单，协作时再根据团队约定补充必要字段。
